## Herb Data Schema
Individual herb detail files are stored as `data/<herb>.json` and adhere to the following format:

```json
{
  "id": "slug-name",
  "name": "Herb Common Name",
  "botanical": "Latin Botanical Name",
  "cycle": "Annual / Biennial / Perennial",
  "description": "Botanical and historical summary",
  "uses": "Culinary, tea, and aromatic uses",
  "tips": "Gardening, sunlight, and irrigation practices"
}
